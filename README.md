# Let's HIIT Up

ブラウザだけで動くインターバルタイマー。HIIT / タバタ式のトレーニング用。

**▶ https://tomoaki-tsuchiya.github.io/Lets-HIIT-Up/**

## 機能

- 準備 → (トレーニング → インターバル) ×セット数 → ラウンド休憩 の繰り返しを設定
- 各ラウンド最終セット後のインターバル、最終ラウンド後のラウンド休憩は自動スキップ
- 残り3秒からのカウントダウン音、フェーズ切替のビープ
- 音声読み上げ（Web Speech API / OS の音声エンジンを使用）
- スリープ防止（Screen Wake Lock、iOS 16.4 以降で対応）
- プリセットの保存・読込、設定の自動保存（localStorage）
- キーボード操作: Space = 一時停止/再開、← → = 前/次フェーズ、Esc = 終了

## 構成

`index.html` の1ファイル完結。ビルド不要、依存ライブラリなし。
ローカルで開く場合はファイルをダブルクリックするだけで動く。

設定とプリセットは localStorage に保存されるため、デバイス・ブラウザごとに独立している。
